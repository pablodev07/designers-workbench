# Recovering a stale key

If a key throws on import, the library was likely republished. Try these
read-only resolvers against `RiY2reCmbX0Jyq7QAFL8SE` **before** escalating.

**Component** — get the page's node IDs via `get_metadata`, then:
```js
const node = await figma.getNodeByIdAsync("<nodeId>"); // e.g. Card 20156:4203
return { type: node.type, key: node.key || null };
```
For a component **set**, get variant node IDs with `get_metadata` on the set,
then resolve the specific variant's key the same way. Do not traverse
`.children` on library nodes inside `use_figma` — it can trip the read-only guard.

**Text style:**
```js
return (await figma.getLocalTextStylesAsync()).map(s => ({ name: s.name, key: s.key }));
```

**Color variable:**
```js
const c = (await figma.variables.getLocalVariableCollectionsAsync())
  .find(c => c.name === "Color Mode");
const out = [];
for (const id of c.variableIds) {
  const v = await figma.variables.getVariableByIdAsync(id);
  if (v.resolvedType === 'COLOR') out.push({ name: v.name, key: v.key });
}
return out;
```

**If a resolver fails or the component no longer exists,** stop and tell the user
to contact **Pascal Mercier** (Slack DM: https://salesforce.enterprise.slack.com/team/WB27UHB9R)
to update the skill. Never guess a key or fall back to hardcoded hex/fontSize.

# Component Usage Rules

**Buttons** — one Brand button per view max. Brand = primary CTA; Neutral =
secondary; Base = tertiary/utility; Destructive = data-loss; Success = positive
completion; Stateful = toggles; Inverse = dark backgrounds only. Labels Title
Case, verb-noun ("Save Record"), never "Click Here". Right-aligned in their container.

**Tabs** — the region-level tabset for either the main content OR the sidebar;
changing a tab swaps all content in that region. Always wrapped in a Card (treat
the sidebar the same as the main section). Overflow menu (never truncate), active
tab never in overflow, never nest a Tabs set directly in another Tabs set. Top of
the region they control.

**Scoped Tabs** — a secondary tabset nested *underneath* one of the primary Tabs
(a sub-tabset inside a primary tab's panel). Only appears within a tab that is
itself part of a Tabs set — never as the region-level tabset. A sidebar or
standalone region uses **Tabs** wrapped in a Card, never Scoped Tabs.

**Cards** — every content region lives inside a Card; nothing floats bare in the
content area. No stroke/shadow on top-level cards. Only nest a card for a
logically distinct sub-section — never around tab-panel content or a Timeline
that already sits in the main card body. Footer = secondary actions / "View All".

**Accordion vs Expandable Section vs Summary Detail** — Accordion for ≥2 related
sections (one open by default); Expandable Section for a single optional detail;
Summary Detail for compact key/value record data.

**Input — View Mode** — record fields use `⚡ Input - Read Only View Mode`, never
raw text nodes. Default variant for standard fields, Editable for inline-edit, Gen AI for AI-populated.

**Data Table** — Base (read-only), Actionable (row actions/selection/sort),
Inline Edit (dirty-cell highlight). 36px rows (104px wrapped). Span edge-to-edge
in list views; add outer border only inside a popover. Empty state when no records.

**Badge** — always static/non-interactive. Default/Light/Info/Success/Warning/
Error. 1–3 words, Title Case, no punctuation. Never for actions; don't stack.

**Pills** — 26px fixed height, hugs width, interactive (receives focus). Sentence
case, 1–2 words, min 4px apart. For multi-select selections.

**Modal** — Small 60% / Medium 70% (default) / Large ≤90%. Title ≤50 chars,
primary button far right, body scrolls (header/footer fixed), Escape closes,
focus trapped. Not for minor notifications (Toast/Alert) or builder contexts (panels).

**Toast** — Success/Error/Warning/Info, top-center, one at a time, <100 chars.
Auto-dismiss 20s for Success-without-link; sticky otherwise. Auto-save success =
inline text, not Toast.

**Alert** — inline full-width banner, 36px, never an overlay. Info/Warning/Error/Offline.

**AI / Agentforce** — AI Cards empty until generated, always show sources +
thumbs up/down. Prompt Composer always bottom-center, Send→Stop while working.
AI form fields marked with a single sparkle, always allow manual override, mark
AI-dirty as pending until confirmed.
