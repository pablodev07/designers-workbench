# Button

A button component wrapping `<lightning-button>` for use in Salesforce Lightning applications. Supports all standard variants, disabled state, and icon placement.

    <tr>

## Usage

```html
<c-button label="Save" variant="brand"></c-button>
<c-button label="Cancel" variant="neutral"></c-button>
<c-button label="Delete" variant="destructive"></c-button>
<c-button label="Download" icon-name="utility:download"></c-button>
```
