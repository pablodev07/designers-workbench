# Data Table

A component wrapping `<lightning-datatable>` for displaying structured data in rows and columns with sorting, row selection, and row-level actions.

## Usage

```html
<c-data-table
  columns={columns}
  data={data}
  key-field="id"
  sorted-by={sortedBy}
  sorted-direction={sortedDirection}
  onsort={handleSort}
  onrowselection={handleRowSelection}
></c-data-table>
```
